- 検索だけを実行して見つかったページと、その本文で確認できたこと：`uv run python -m app.retrieval "LoRA QLoRA 違い"` の上位5件は、1位 p.52、2位 p.51、3位 p.60、4位 p.47、5位 p.61。p.52（元の重みは固定し、小さな行列A・Bだけを学習する。QLoRAは元の重みを4bitに圧縮する）と p.51（LoRAは本体を固定し小さな追加部分だけ更新、QLoRAはさらに本体を4bitに圧縮）が答えの根拠。p.60・p.61 は演習の手順、p.47 はRAGとFTの比較のページで、LoRA・QLoRAの語は出てくるが固定・学習の説明ではなく、似た用語が出ているだけだった。

- 取得した情報が足りなかった例、取得できたのに回答へ使えなかった例：足りなかった例は今回は見つからなかった（Treeは p.52 だけで答えたが、この質問は p.52 だけで足りる）。取得できたのに使えなかった例は、全文投入。p.51, p.52 を引用したのに答えを書かなかった。`app/agent.py` の4つの指示文（45・55・66・74行目）に「宿題の答えそのものは書かず、考え方のヒントで導く。」という行があり、これが原因ではないかと考えられる（原因の検証はしていない）。Graphは10ページ中8ページが質問に関係せず、根拠の2ページは入口の時点で取れていた。
